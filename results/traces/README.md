# Local-only decision trace

The compressed decision_trace.jsonl.gz in this folder is the full measured Traffic-Qwen trace. It is retained in the local staging directory for audit and is ignored by Git because its observations derive from Jinan traffic data whose redistribution terms were not verified. Its raw source was copied from the JevLight experiment artifacts, then compressed without changing any JSON records. Source and compressed hashes are recorded in artifacts_manifest/excluded_large_files.json.

No trace sample is published for the same provenance reason. The measured summary metrics, figures, and anonymized aggregate series are in the tracked result reports.
